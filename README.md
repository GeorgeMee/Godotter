# Godotter

Workflow-first, CLI-first, headless-friendly AI-assisted development system for Godot projects.

## Current Status

This repository is in scaffold stage. The initial focus is:

- deterministic workflows
- structured tooling
- patch-based editing
- validation-first execution
- recoverable runtime

## Directory Notes

- `Docs/`: product and architecture documents
- `References/`: upstream references and design inspiration
- `src/`: Python source root with the main package in `src/godotter/`
- `tests/`: automated test suite
